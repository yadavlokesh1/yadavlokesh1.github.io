# Lokesh Yadav — Portfolio

Personal portfolio website of Lokesh Yadav - Windows Administrator | Cloud & Virtualization.

🌐 Live at: https://yadavlokesh1.github.io

## AKS Deployment Project

Containerized this portfolio site and deployed it on Azure Kubernetes Service (AKS).

**Tech used:**
- Docker
- Azure Container Registry (ACR)
- Azure Kubernetes Service (AKS)
- kubectl

**Steps followed:**
1. Built Docker image of the portfolio site
2. Pushed image to Azure Container Registry
3. Created AKS cluster on Azure
4. Deployed using Kubernetes manifest
5. Exposed via LoadBalancer with public IP
